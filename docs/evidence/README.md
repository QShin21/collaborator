# 证据记录

这里放每一次**真实环境**里的检查记录：Windows 运行器上的工作流结果（E2）、真机校准与验收（E3）、真实模型的评测（E4）、试用结论（E5）。
一次一份文件，按 [`TEMPLATE.md`](TEMPLATE.md) 填写，文件名 `EV-年份-序号.md`；台账 [`../verification.md`](../verification.md) 里对应的行链接到这里。

**目前这里没有任何记录。** Linux 上的自动化测试（E1）不在这里记，它们由测试本身说明。

不要放进来的东西：任何草稿、聊天文字、密钥、带用户名的路径。证据包 zip 本身不进仓库，只记它的文件名；
其中的 `structure.json`（只有控件类型、位置和文字长度）可以放进 `tests/fixtures/` 做回放测试。
