## 伴行 0.4.0a2 · Windows 预览版

你和一个模型做一段长对话时，伴行请**另一个模型**在旁边读它：记下这段对话立在什么上面，回头去查那些只是说过、没有查过的地方；
思路走偏、而且正影响眼下的方向时，出一条气泡，附出处和一句可以带回去问主模型的话。它只读，目标和每一步都由你定。

### 下载哪个

| 文件 | 用途 |
| --- | --- |
| `Banxing-v0.4.0a2-windows-x64-setup.exe` | **安装版（推荐）**。双击安装，不需要管理员权限；装到 `%LOCALAPPDATA%\Programs\Banxing`，在开始菜单里创建「伴行 Banxing」，可勾选桌面快捷方式；在「设置 → 应用」里卸载。 |
| `Banxing-v0.4.0a2-windows-x64.zip` | 便携版。解压后双击 `Banxing.exe`（保留同目录的 `_internal` 文件夹）。 |
| `*.sha256` | 上面两个文件各自的 SHA-256 校验值。 |

程序和安装程序都**没有代码签名**：Windows 提示「已保护你的电脑」时点「更多信息 → 仍要运行」。安装向导的页面是英文的。

### 这一版改了什么

**安装程序（新）**

- 按用户安装、创建开始菜单入口和可选的桌面快捷方式、登记卸载项；再装一次即覆盖升级。
- **升级和卸载都不动你的数据**：模型配置、加密保存的 API Key、你选择保存的账本都在 `%APPDATA%\Banxing`，安装程序不碰它。
  想彻底清掉，卸载前在右键菜单里点「清除本机数据」，或卸载后手动删除这个文件夹。
- 从 0.4.0a1 的 zip 版换过来：直接安装即可，数据在同一个文件夹里，会接着用；旧的解压目录自己删掉。

**界面**

- **使用说明**：第一次启动自动打开，以后在右键菜单「使用说明…」里。三步——配置旁听用的模型、选一条对话、气泡出现时怎么办——
  每一步标出你现在到了哪里，并带一个直接去做的按钮。
- **账本窗口**：顶上一行汇总（正在影响方向 / 没查过 / 有依据各几条）；条目按依据分色——没查过的黄色、被推翻的红色、有依据的绿色；
  可以滚动、可以拉大，刷新时停在你正在读的位置。
- **气泡**：疑点类型做成色块，并写明它是「正在影响方向」还是「记一笔」。
- **鼠标停在伴行上**：显示当前状态（没配置 / 没在旁听 / 读到第几轮、账上几处疑点）和单击会做什么。
- **对话框**：同一种只开一个，再点一次是把已开的那个提到前面；按 Esc 关闭；出现在屏幕中间而不是左上角；标题栏用伴行自己的图标。
- 选对话的窗口里，在路径框按回车即读取。修掉了模型设置说明里露出来的 `**` 符号。

没有改动的：账本和气泡的全部规则、逐条同意、只读不写、密钥与线路的各项约束、提示词（`audit-1.0`、`blind-1.0`）。
设置文件的格式不变，只多了一个「使用说明看过了」的标记。

### 怎么用

1. 安装后从开始菜单打开「伴行 Banxing」。屏幕右下方出现一个蓝色的小圆脸，第一次会弹出使用说明。
2. 右键伴行 →「旁听用的模型…」：选模型服务、填 API Key。最好不是你正在对话的那一个。
   没有 Key 想先看流程，选「离线演示」（关键词规则，不联网，**不代表真实的判断质量**）。
3. 右键伴行 →「旁听一条对话…」：在聊天网页里全选、复制后点「从剪贴板读取」；或选一份 ChatGPT 导出、Codex / Claude Code 的会话文件、文字稿。
   窗口里写明这条对话从第几轮起发往哪个地址，确认后点「同意并开始旁听」。这之前不发送任何东西。
4. 照常和主模型工作。气泡出现时：「查看依据」看原文出处；「复制这句追问」后粘贴给主模型；
   「我知道，有意如此」「这条不成立」会记进账本，同类提醒不再出现。
5. 单击伴行 = 现在看一眼；右键 →「账本…」看这段对话的立足点、这次它回头查了什么、提交过哪些轮次多少字几次请求。
6. 网页聊天又长了：再全选复制一次，右键 →「对话有更新：从剪贴板再读一次」。

更完整的说明在安装目录的 `README.txt`。

### 验证状态——请照实理解

证据等级的定义见随包的 `VERIFICATION.md`（它写于这次构建之前，其中「等 CI」的几处说的是当时）。

- **自动化（Windows 运行器，E2）**：这次发布的构建在 GitHub 的 Windows 运行器上跑过全部单元测试、程序自检（含把每个对话框开两次、Esc 关闭、
  关掉再开）、打包后程序的自检，以及安装检查：静默安装 → 检查文件、开始菜单与桌面快捷方式、卸载项 → 运行安装后的程序 → 覆盖再装一次 →
  静默卸载 → 检查程序、快捷方式、卸载项都已移除而 `%APPDATA%\Banxing` 里的文件还在。这些都通过，发布才会出现。
- **可视检查（仅 Linux）**：新界面在开发机的 Linux 显示上截图看过。**没有人在 Windows 上看过这些窗口。**
- **没有验证的**：
  - 旁听的模型**判断得准不准**——没有用任何真实模型、任何真实对话评估过；
  - 真实的 ChatGPT 导出、Codex / Claude Code 会话、网页复制的聊天页面读得对不对；
  - 真实 Windows 桌面上的交互：气泡是否不抢焦点、托盘、高分屏、多显示器；
  - 安装向导由人点一遍、SmartScreen 的实际提示、Windows 10 / 11 各版本、从 0.4.0a1 升级的实际过程。

验收步骤见 `ACCEPTANCE.md`。发现问题请到仓库的 Issues 里说——只描述现象和结构，不要贴对话内容。

**English.** `…-setup.exe` is a per-user installer (no administrator rights; Start Menu entry, optional desktop shortcut,
uninstall from Settings → Apps); the `.zip` is the portable build. Neither is code-signed. Upgrading and uninstalling leave
`%APPDATA%\Banxing` (settings, protected API key, a kept ledger) alone. New in this version: a first-run guide, a colour-coded
and scrollable ledger window, status on hover, one-instance dialogs that close on Esc. This build passed the automated tests,
the packaged self-test and a silent install / run / reinstall / uninstall check on a Windows CI runner. The supervising model's
judgement has **not** been evaluated with a real model or on real conversations, and nobody has used the app or clicked through
the installer on a real Windows desktop yet.
